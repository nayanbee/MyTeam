# MyTeam

MyTeam is an instructor management and performance platform for boutique fitness studios.

The product is being designed to integrate with existing studio management platforms such as Mariana Tek while keeping the booking and studio schedule system as the source of truth.

## Product scope

MyTeam is focused on the instructor-management layer, including:

- Instructor schedules across multiple studio locations
- Cover requests and open-shift workflows
- Grouped shift availability and manager approval
- Instructor, studio and class-level performance analytics
- Client retention and rebooking analysis
- Post-class client feedback
- Instructor evaluations and development
- Team communications
- Qualification and compliance tracking

## Integration approach

The initial Mariana Tek integration is intended to be primarily read-only. Class sessions, instructors, locations, reservations and attendance data are synchronized from Mariana Tek for operational workflows and analytics. Schedule changes remain managed in Mariana Tek.

## Status

Early development and API feasibility testing.
